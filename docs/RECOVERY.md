# Восстановление из резервной копии

Резервная копия создаётся при реальной установке, обновлении или удалении; `status` и `--dry-run` её не создают. Это прежние файлы приложения и плагина, а не снимок всей прошивки. При первой установке прежних файлов может не быть. Копии накапливаются без автоматической ротации.

В режиме `--keep-config` настройки остаются на рабочих местах. При архивном удалении без флагов `/var/opt/aa` переносится в отдельную копию на том же разделе. При `--purge` обе папки резервных копий стираются после завершения транзакции: восстановить их этим способом уже нельзя.

Обычные ошибки при замене файлов скрипт обрабатывает автоматически. Этот раздел нужен для ручного возврата после успешного обновления/удаления или прерывания, которое скрипт не мог обработать.

Сначала открыть root SSH, перейти через `on -f /net/hu-omap/ /bin/sh`, выполнить **Force Stop** в меню Android Auto и убедиться по `pidin -F '%a %A'`, что процесса `nbt-aad` больше нет. Раздел для восстановления открыть командой:

```sh
mount -o remount rw /fs/sda0
```

Выбрать конкретную резервную папку по выводу установщика и `operation.log`. Подставить её полный путь вместо примера. Не выбирать случайную или просто последнюю папку: неудачный запуск мог сохранить только промежуточные файлы.

```sh
B=/opt/nbt-aad-usb-tools-backups/20261104-140000-12345-install
ls -l "$B"
```

В `aa` и `plugin` находятся прежние каталоги. `staged-*` — ещё не размещённые новые файлы; `failed-*` — файлы, убранные при откате. Отсутствие `aa`/`plugin` может означать первую установку или уже выполненный откат; тогда восстанавливать из этой папки нечего.

Перед возвращением резервного каталога нужно освободить его исходный путь, сохранив нынешнее содержимое. Выполнять только для тех компонентов, которые действительно есть в резервной папке:

```sh
# Возврат прежнего /opt/aa:
if [ -d "$B/aa" ]; then
    if [ -e /opt/aa ]; then
        [ ! -e "$B/before-manual-restore-aa" ] && mv /opt/aa "$B/before-manual-restore-aa"
    fi
    [ ! -e /opt/aa ] && mv "$B/aa" /opt/aa
fi

# Возврат прежнего плагина:
if [ -d "$B/plugin" ]; then
    if [ -e /opt/hmi/ID5/data/ro/Plugins/NbtAad ]; then
        [ ! -e "$B/before-manual-restore-plugin" ] && mv /opt/hmi/ID5/data/ro/Plugins/NbtAad "$B/before-manual-restore-plugin"
    fi
    [ ! -e /opt/hmi/ID5/data/ro/Plugins/NbtAad ] && mv "$B/plugin" /opt/hmi/ID5/data/ro/Plugins/NbtAad
fi
```

После удаления постоянные настройки сохранены отдельно на `/var`. Их точный путь записан в `var-backup-path`:

```sh
cat "$B/var-backup-path"
```

Подставить выведенный путь в `V`. При необходимости вернуть настройки аналогичным способом на том же разделе:

```sh
V=/var/opt/nbt-aad-usb-tools-backups/20261104-140000-12345-uninstall
if [ -d "$V/aa" ]; then
    if [ -e /var/opt/aa ]; then
        [ ! -e "$V/before-manual-restore-settings" ] && mv /var/opt/aa "$V/before-manual-restore-settings"
    fi
    [ ! -e /var/opt/aa ] && mv "$V/aa" /var/opt/aa
fi
```

Если любая команда сообщает об ошибке, дальше не продолжать. После успешного возвращения каталогов выполнить `sync`, если эта утилита присутствует, и перезагрузку ГУ. На штатных образах без `sync` не заменять его задержкой, выдавая её за принудительный сброс кэшей. Возврат настроек также возвращает прежний флаг автоматического запуска, если он был включён.

Эти команды сохраняют текущие файлы перед восстановлением. Резервные копии автоматически не очищаются. Они не являются полной копией прошивки ГУ и не включают кодирование, FSC, загрузчик или другие системные разделы.
